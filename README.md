# Documentacao do Projeto Raizes_Do_Nordeste_API

Esta pasta concentra os artefatos de documentacao da API Raizes do Nordeste.

## Arquivos principais

- `documentacao_projeto.md`: documento principal da entrega, com contexto, objetivos, requisitos, arquitetura, regras de negocio, seguranca, LGPD, testes e conclusao.
- `api.md`: referencia dos endpoints implementados, com permissao, parametros e exemplos.
- `manual_execucao.md`: passo a passo para instalar, preparar o banco, executar a API e validar o ambiente.
- `test_plan.md`: plano de testes funcional da API.
- `raizes_api.postman_collection.json`: colecao Postman com cenarios de teste manuais.
- `der.md` e `der.drawio`: diagrama entidade-relacionamento do banco de dados.

## Ordem sugerida de leitura

1. Leia `documentacao_projeto.md` para entender o projeto completo.
2. Abra `der.drawio` no draw.io/diagrams.net para visualizar o modelo de dados.
3. Use `manual_execucao.md` para rodar o sistema localmente.
4. Consulte `api.md` ou a colecao Postman para testar os endpoints.
