# Documentacao do Projeto

Arquivos usados na entrega tecnica da API Raizes do Nordeste.

## Arquivos principais

- `documentacao_projeto.md` e `documentacao_projeto.pdf`: documento principal da entrega.
- `api.md`: referencia dos endpoints implementados, com permissao, parametros e exemplos.
- `manual_execucao.md`: passo a passo para instalar, preparar o banco, executar a API e validar o ambiente.
- `test_plan.md`: plano de testes funcional da API.
- `raizes_api.postman_collection.json`: colecao Postman.
- `der.md` e `der.svg`: modelo de dados.
- `diagrama_casos_uso.svg`: atores e casos de uso.
- `diagrama_arquitetura.svg`: camadas do projeto.
- `diagrama_classes.svg`: classes de dominio.
- `diagrama_fluxo_pedido.svg`: fluxo pedido/pagamento.

## Ordem sugerida de leitura

1. Leia `documentacao_projeto.md` para entender o projeto completo.
2. Abra os diagramas SVG para visualizar modelo, atores e fluxo.
3. Use `manual_execucao.md` para rodar o sistema localmente.
4. Consulte `api.md` ou a colecao Postman para testar os endpoints.
